# B-roll library (your logos and screenshots)

Drop images here, named after what they show: `instagram.svg`, `whatsapp.png`, `meta-ads.jpg`.
For Arabic names add a `tags.json` file next to them:

    {"whatsapp.png": ["واتساب", "وتساب"]}

When you say one of those names in a reel, the image is copied into that reel automatically (a logo card can then use it).
Nothing is changed or deleted in this folder, and nothing is added if you didn't say the name.
The images themselves stay on your Mac (they are not uploaded to GitHub).
