# Style references (for designing new templates)

Drop motion references here, one folder per style, same layout as the MoAssets library:

    library/style_refs/<slug>/video.mp4     preview (stays on your Mac: videos are never put in git)
    library/style_refs/<slug>/poster.webp   still (stays on your Mac)
    library/style_refs/<slug>/prompt.txt    the style prompt (kept in git)
    library/style_refs/<slug>/meta.json     title, tags, source link (kept in git)

You can also copy the whole MoAssets `entries/` folder in here.

These are other creators' work: **reference only**. Nothing from here is shown in a reel.
Claude rebuilds a style as a new template in Hesham's brand (colours, Readex Pro, Arabic right-to-left, 9:16),
renders a sample, and only templates Hesham approves are added to templates/blocks/.
